# Timeline item

One dated event from the documents, in their words, with the sources it came from.

## Anatomy

- Date column (8rem): `text-small font-medium tabular-nums text-ink-secondary`, formatted "14 Jan 2026". Ranges as the documents give them ("Feb–May 2026").
- Rail: `border-l border-line-strong` with a 10px `bg-control` dot ringed in `border-surface`.
- Event: verbatim, `text-body`, `lang="bg"`.
- Sources: full chips (1–2), compact (3–4), group (5+).

## Rules

- Oldest first. Undated events go last under "Date not in the documents".
- Don't merge two documents' wording into one event. Two sources that say the same thing are one event with two chips.
