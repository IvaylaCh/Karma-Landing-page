# Cohort summary

For a trial with several cohorts: the best-matching cohort with its counts, and every other cohort collapsed to one row with its own counts.

## Anatomy

- Eyebrow: "Cohorts · 4 in this trial" (`text-label uppercase`).
- Heading: **"Best-matching cohort: Phase 1a"** (`text-heading`), then the cohort's own description and criteria count.
- Its four count pills.
- "Other cohorts": one collapsed row each, chevron + name + counts line. Expanding a row opens that cohort's criterion matrix.

## Copy

- "Best-matching cohort" and "match profile" are the only approved phrasings with that word; the words Karma never uses are listed in Do's and don'ts.
- The counts are the evidence for the ordering. Don't add a score, a percentage or a recommendation.
