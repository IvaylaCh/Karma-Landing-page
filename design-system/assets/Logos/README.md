# Logos

The Karma logo, **Twin**: a disc with two spiral grooves. Every file is plain shapes: the name is outlined from Geologica SemiBold, so no font is needed, and nothing carries script, styles or outside links.

The mark has two drawings. The **dotted** one (330 dots, each dot's size and colour stepping through the brand palette) is for 64px tall and up. The **solid** one (the same disc and spirals as one filled shape) is for anything smaller. Use a lockup (mark and name) unless the space is square.

## Light grounds

- `karma-lockup.svg` — dotted mark and name, 96px tall as drawn. Title slides, covers, the landing page on a light section.
- `karma-lockup-solid.svg` — solid mark and name, 28px tall as drawn. The 64px app header.
- `karma-mark.svg` — the dotted mark alone, 64px tall and up.
- `karma-mark-solid.svg` — the solid mark alone in `accent` `#4965EB`, from 16px.
- `karma-wordmark.svg` — the name alone in `ink` `#131313`.

## Dark brand surfaces

The same five, drawn for `brand-ground` `#131313`: `karma-lockup-reversed.svg`, `karma-lockup-solid-reversed.svg`, `karma-mark-reversed.svg`, `karma-mark-solid-reversed.svg` (in `periwinkle` `#818FF2`) and `karma-wordmark-reversed.svg` (in `brand-ink` `#E7E7E7`).

## One colour and the icon

- `karma-mark-mono.svg` — the solid mark filled with `currentColor`, so it takes the text colour: one-colour print, stamps, anything that must follow the surrounding ink.
- `karma-icon.svg` — the tab and app icon: the solid mark in `periwinkle` on a `carbon` rounded square. Export it to PNG at 180px for the Apple touch icon and to ICO at 16, 32 and 48px. For the 192px and 512px web-manifest icons, square the corners and scale the mark to 70% of the tile, because the system rounds them itself.

Clear space: the height of the "k" on every side. Smallest sizes: dotted mark 64px tall, solid mark 16px, solid lockup 20px tall, the name alone 14px tall. For a dark ground take the `-reversed` file; never recolour a light one.
